## Что делает мод

На больших серверах в списке игроков (`Tab`) десятки ников, и нужных — друзей, соклановцев, врагов или модераторов — в нём не найти. Tab Name Dimmer раскладывает игроков по вашим группам:

- **затемняет** всех, кто не в ваших группах, и **поднимает** отслеживаемых наверх;
- может **показать только отслеживаемых** или вывести их отдельным компактным списком на экран;
- **окрашивает** ники в цвет группы;
- **подсвечивает контуром** игроков из группы прямо в мире, а остальных делает полупрозрачными;
- **сообщает**, когда отслеживаемый игрок зашёл или вышел;
- умеет переносить в конец или прятать AFK-игроков.

Группы бывают общими для всех серверов и своими для конкретного сервера. Мод работает только у вас и ничего не отправляет на сервер.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) `0.19.3` или новее для Minecraft 26.3.
2. Положите в папку `mods` [Fabric API](https://modrinth.com/mod/fabric-api) `0.161.0+26.3` или новее.
3. Положите в `mods` файл `tab-name-dimmer-1.2.3.jar` (как собрать — в разделе [Сборка](#сборка-из-исходников)).
4. Рекомендуется [Mod Menu](https://modrinth.com/mod/modmenu) `21.0.0`: через него открываются настройки.

Нужна Java 25.

## Первые шаги

1. Откройте **Mod Menu → Tab Name Dimmer → значок настроек**.
2. Нажмите «Группы и профили». Там уже есть группа «Default» зелёного цвета.
3. Переименуйте её, например в «Друзья», выберите цвет.
4. Нажмите «Изменить участников» и впишите ники. Можно открыть «Игроки онлайн» и добавить игроков кликом.
5. Нажмите «Сохранить» на главном экране.
6. На сервере откройте список игроков (`Tab`) и зажмите `Shift`: друзья окажутся наверху, остальные — затемнены.

## Как включается эффект

Мод не меняет список постоянно — только когда эффект **активирован**. Способ задаётся настройкой «Активация»:

| Режим | Как работает |
|---|---|
| Удерживать любой Shift (по умолчанию) | эффект есть, пока зажат левый или правый Shift |
| Удерживать свою клавишу | эффект есть, пока зажата своя клавиша |
| Переключатель своей клавишей | одно нажатие включает, следующее выключает |

Своя клавиша задаётся в **Настройки → Управление → Tab Name Dimmer** (по умолчанию левый Alt).

Затемнение и сортировка работают в списке `Tab`. Подсветка контуром и прозрачность в мире тоже работают, только когда список `Tab` открыт и эффект активирован.

## Группы игроков

Экран «Группы и профили».

### Группа

| Поле | Что значит |
|---|---|
| Название группы | любое |
| Цвет группы (#RRGGBB) | цвет ника и контура; кнопка рядом перебирает готовые цвета |
| Группа включена | выключенная группа сохраняется, но не действует |
| Окрашивать ники в Tab | ники участников красятся в цвет группы |
| Контур группы | участники подсвечиваются контуром в мире |
| Прозрачность группы | участники становятся полупрозрачными в мире |
| Приоритет группы | у кого выше, тот побеждает, если игрок в нескольких группах, и стоит выше в Tab |

- Кнопки `<` и `>` переключают группы, «Добавить группу» создаёт новую, «Дублировать» копирует группу с участниками.
- «Выше» и «Ниже» меняют порядок. При равном приоритете побеждает группа выше в списке.
- Приоритет меняется кнопками `-` и `+` (с Shift — на 10), клик по значению сбрасывает его на 0.
- «Удалить группу» требует повторного нажатия.

### Участники

«Изменить участников» открывает список ников группы.

- Вписывайте ники по одному, кнопка «Добавить».
- **Маски:** `*` — любой текст, `?` — один символ. `Clan_*` добавит всех, чей ник начинается с `Clan_`, `Bot?` — `Bot1`, `BotA` и так далее.
- Поиск по никам, «По алфавиту» (сортирует и убирает повторы), «Очистить».
- «Игроки онлайн» показывает всех на сервере; рядом видно, в какой группе игрок уже состоит, и совпадает ли он по маске.
- Регистр ников не учитывается, пока выключено «Учитывать регистр».

### Глобальные группы и группы сервера

Переключатель «Редактируется: Глобальные группы / Группы этого сервера» выбирает, что вы правите.

- Глобальные группы действуют на всех серверах.
- Свои группы сервера **полностью заменяют** глобальные на этом сервере.
- При первом переключении создаётся копия глобальных групп. Если её не изменить, она удаляется при выходе.
- «Использовать глобальный» удаляет группы сервера, и там снова действуют глобальные.

Строка под заголовком подсказывает, что действует на текущем сервере.

Изменения применяются кнопкой «Сохранить» на главном экране или сразу `Ctrl+S` на вложенных экранах. Несохранённые изменения отмечены строкой «Есть несохранённые изменения».

## Режимы списка

Настройка «Режим»:

| Режим | Что происходит |
|---|---|
| Плавная сортировка (по умолчанию) | отслеживаемые игроки плавно поднимаются наверх, остальные затемняются |
| Только отслеживаемые | в списке остаются только игроки из групп |
| Отдельный компактный список | обычный список не меняется, а отслеживаемые выводятся отдельным списком на экран (см. [Компактный HUD](#компактный-hud)) |

«Сортировка внутри группы»: порядок сервера (по умолчанию), по нику или по пингу. «Скорость сортировки» задаёт, как быстро игроки переезжают в списке.

## Подсветка и прозрачность в мире

- **Контур группы.** Игроки из группы с включённым контуром подсвечиваются её цветом, как от эффекта свечения. Видно только у вас.
- **Прозрачность неотслеживаемых.** Игроки не из ваших групп становятся полупрозрачными, а настройка «Видимость прозрачных игроков» задаёт, насколько. Удобно, чтобы в толпе выделялись свои.
- **Прозрачность группы** делает полупрозрачными участников конкретной группы.

Всё это работает, пока открыт список `Tab` и эффект активирован, только для игроков в прямой видимости.

## AFK-игроки

Многие серверы помечают отошедших игроков значком или текстом `[AFK]`. Настройка «AFK-игроки»:

- «Как обычно» (по умолчанию);
- «В конец» — AFK-игроки переносятся в конец списка. Ванильный список показывает не больше 80 записей, поэтому при большом онлайне видимые места достаются активным игрокам;
- «Скрыть».

«Коды значков AFK» — значок AFK из ресурспака сервера: его код (`A416`, `U+A416`) или сам символ, несколько через пробел. Пустое поле — узнавать только текстовые метки вроде `[AFK]` и `zzz`.

## Уведомления о входе и выходе

- «Уведомления о входе/выходе» (вкл.) — сообщение «Отслеживаемый игрок … вошёл на сервер».
- «Краткая запись [+/-] Ник» (выкл.) — коротко: `[+] Ник`, `[-] Ник`.
- «Звуки входа/выхода» (выкл.) — звук при входе и выходе.

## Компактный HUD

Кнопка «Компактный HUD» на главном экране. Используется в режиме «Отдельный компактный список».

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Положение HUD | снизу по центру | сверху слева, сверху справа, снизу слева, снизу по центру, снизу справа |
| Колонки HUD | 1 | сколько колонок |
| Максимум строк HUD | 20 | сколько строк в колонке |
| Аватары в HUD | вкл. | головы игроков |
| Пинг в HUD | вкл. | пинг каждого игрока |

## Импорт и экспорт

- «Импорт .txt» — добавить ники из текстового файла (по нику на строку, до 1 МиБ).
- «Экспорт профиля» и «Импорт профиля» — сохранить группы в файл и загрузить их, например чтобы поделиться с другом.

## Файлы

`config/tab-name-dimmer.json` — все настройки и группы. Запись атомарная, рядом резервная копия `.bak`; мод восстанавливает из неё и повреждённый, и удалённый файл. Правки файла вручную подхватываются примерно через секунду.

Пример:

```json
{
  "schemaVersion": 2,
  "enabled": true,
  "dimOpacity": 0.3,
  "displayMode": "ANIMATED_SORT",
  "activationMode": "HOLD_SHIFT",
  "afkHandlingMode": "MOVE_TO_END",
  "globalProfile": {
    "name": "Global",
    "groups": [
      { "name": "Friends", "color": 5635925, "priority": 10, "enabled": true, "members": ["PlayerName", "Clan_*"] }
    ]
  }
}
```

## Частые вопросы

**Ничего не меняется в списке Tab.** Эффект работает, пока он активирован: по умолчанию нужно держать `Shift` при открытом `Tab`. Режим активации меняется в настройках.

**Нет контура у друзей.** Включите «Контур группы» у их группы. Контур виден, пока открыт `Tab` и эффект активирован.

**На одном сервере группы другие.** На этом сервере есть свои группы, они заменяют глобальные. Нажмите «Использовать глобальный», чтобы вернуть общие.

**Игрок попадает не в ту группу.** Если он подходит под несколько групп, побеждает группа с наибольшим приоритетом, а при равном — та, что выше в списке.

**AFK-игроки не распознаются.** Сервер помечает AFK своим значком из ресурспака. Узнайте его код и впишите в «Коды значков AFK».

## Сборка из исходников

Нужна JDK 25.

```powershell
git clone https://github.com/ServChan/tab-name-dimmer.git
cd tab-name-dimmer
.\gradlew.bat build
```

На Linux и macOS используйте `./gradlew`. Готовый файл: `build/libs/tab-name-dimmer-1.2.3.jar`.
